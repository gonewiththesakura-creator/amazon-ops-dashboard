# ELOVNOVA 亚马逊数据体系工作台 (Amazon Ops Copilot)

基于卖家精灵（SellerSprite）49 项专业 MCP 接口构建的跨境电商运营、选品与资金抗风险全景数据系统。
架构设计全面依据 **2026-09-09 会议讨论草稿与手写架构图** 落地开发。

---

## 🌟 核心业务架构与四大板块

> **为什么需要自行搭建本系统？**
> 卖家精灵界面默认通常只展示二级大类，三类/四类细分市场（如颈椎枕/蝴蝶枕、腰枕）必须逐店、逐 SKU 进行深度穿透与同款竞品调取。本系统专门解决该痛点。

### ① 自有产品分析 & 前 100 名同款竞品监测 (单个产品 · 三类穿透)
* **预置 5 大自有在售核心 SKU**：
  * `LIU-B0GYH8WT22` / 刘总枕头 (`B0GYH8WT22`)
  * `ELOVNOVA-Gray` / 江西灰色 (`B0GY2TDLTZ`, Parent: `B0GY2VPQPD`)
  * `ELOVNOVA-Blue` / 江西蓝色 (`B0GY2WGTDM`, Parent: `B0GY2VPQPD`)
  * `NB-LP001-MG` / 腰枕-灰石 (`B0HJWZM439`)
  * `NB-LP001-MSG` / 腰枕-流星灰 (`B0HJX1MGBF`, Parent: `B0HJWR8ZLB`)
* **价格与 BSR 排名走势双轴曲线**：评估标价调整与促销折扣对权重的实际杠杆效应。
* **同类前 100 名同款头部竞品实时监测榜**：自动调取同类目热销竞品（如 Derila 蝴蝶枕等）的月销量、售价、大类排名与评价，支持一键直达亚马逊。

### ② 行业市场分析 (二类大盘到四类细分)
* 直通四级细分节点：
  * `Neck & Cervical Pillows (颈椎枕/蝴蝶枕: 1055398:1063252:1199122:3732111)`
  * `Lumbar Support Pillows (腰枕: 1055398:1063252:1199122:3732051)`
* **价格带机会折柱图**：在售商品供给数 vs 销量贡献占比，一眼锁定蓝海定价区间。
* **CR4 / CR8 品牌集中度玫瑰图** 与 **卖家归属地分布**（中国跨境卖家 vs 美本土卖家占比）。

### ③ 待开发产品 & 选品拓展 (判断“能否做、做多少”)
* **U型枕 / 旅行枕**：差旅强需求，复用现有记忆棉供应链。
* **人体工学腰枕**：办公久坐与车载强需求，深耕现有灰石/流星灰款式。
* **电动加热按摩枕**：高客单价高利润，需关注带电认证与退货率控制。
* **跨品类拓展（如儿童学习用品套装）**：先看二三类大盘走势，再定四类组合打法。

### ④ 爆单补货测算 & 资金池抗风险 (完整还原手写草稿测算模型)
* **断货风险天数与红黄绿灯预警**：
  * 案例：现有备货 $200 \div$ 日销量 $50 =$ **只够卖 4 天 🚨 亮红灯：断货高危！**
* **补货周期与紧急空运**：
  * 海运周期 30 天需备 $1,500$ 件，计算断货缺口窗口并测算需应急空运补货件数。
* **综合成本与准备资金池**：
  * 批量大货（如 1 万件 $\times$ 50 元）$=$ 货款 50 万元 $+$ 综合运费（海运+空运）$=$ **合计约需准备 100 万元流动资金池**。
* **灰色枕头案例警示**：*“补多少货 ➔ 运费（补少则单位运费高、不划算；补多需兼顾资金占用）”*。

## 🚀 极速启动

系统内置离线化独立依赖（Apache ECharts、Tailwind、FastAPI），一键即可运行：

```bash
# 1. 克隆或进入项目目录
cd amazon-ops-dashboard

# 2. 运行启动脚本（会自动启动服务并调起浏览器）
python start.py
```

启动后在浏览器打开：
👉 **http://127.0.0.1:8000**

## 📁 目录架构

```text
.
├── backend/
│   ├── config.py                 # 全局配置（MCP URL 与 Secret 密钥）
│   ├── mcp_client.py             # 异步 MCP 客户端（自动解包与缓存）
│   ├── cache.py                  # SQLite 本地查询缓存引擎（24小时 TTL，保护 API 配额）
│   ├── main.py                   # FastAPI 服务路由与静态资源挂载
│   └── services/
│       ├── asin_service.py       # ASIN 画像、BSR 与前 100 竞品榜单
│       ├── market_service.py     # 四级类目节点、价格带与品牌集中度
│       ├── keyword_service.py    # 关键词搜索/购买趋势与四象限机会矩阵
│       ├── pipeline_products.py  # 待开发产品监测 (U型枕/腰枕/按摩枕)
│       ├── replenishment_service.py # 爆单补货与资金池测算模型
│       └── ai_diagnostics.py     # 5 维能力雷达评分与落地运营指南
├── frontend/
│   ├── index.html                # 现代化深色响应式运营看板 UI
│   ├── app.js                    # 前端 ECharts 图表渲染与计算控制器
│   ├── styles.css                # 定制看板与打印导出样式
│   ├── echarts.min.js            # 本地 Apache ECharts 引擎 (1.02 MB)
│   └── tailwind.min.js           # 本地 Tailwind CSS 引擎
├── start.py                      # 一键启动脚本
├── test_server.py                # 全链路自动化测试脚本
└── README.md                     # 项目说明文档
```
